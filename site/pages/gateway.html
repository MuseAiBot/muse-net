03 / Share job

Closed means closed.

FED-NET does not confuse “the upstream pipe works” with “guests may enter.” The gateway opens only when every sharing control is explicit.

Default state

Listen port zero. Empty guest allowlist. Empty forwarding rules. Zero per-guest bandwidth. No useful path for guest traffic.

Explicit state

Only a configured port, exact identities, valid forwarding rules, and a positive bandwidth cap can make the policy report OPEN-CONFIGURED.
