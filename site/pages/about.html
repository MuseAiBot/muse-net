Project brief

The pipe is not the policy.

MuseAi-FED-NET is the operator and sharing policy for FedNet. The connection can be healthy while the gateway remains closed. That distinction is the whole point.

Static deployment

This site uses relative HTML links, local assets, a symbol SVG favicon, and no server-side assumptions. It can be published from GitHub Pages or Cloudflare Pages.

Change the URL once

Update site/site-config.js with the final Pages or custom-domain URL. Captions, footer links, and visual stamps use that shared value.

Live-test boundary

The website can explain the system and the repository can run policy tests. Live proof still requires the authorized Windows PC, connected Android phone, administrator access, and required adapter.

Source of truth

The implementation lives in desktop/fed_net.py and the default policy lives in fed-net/gateway.json.
